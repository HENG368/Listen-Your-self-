# Listen-Your-self-

A simple Dart/Flutter music app UI demo.

## Features
- Switch music order mode between **Normal**, **Reverse**, and **Shuffle**.
- Clean, modern UI for a music queue list.

## Structure
- `lib/main.dart`: main app UI and order mode logic.
- `pubspec.yaml`: Flutter package configuration.

## Run
1. Install Flutter SDK.
2. From repository root:
   - `flutter pub get`
   - `flutter run`
